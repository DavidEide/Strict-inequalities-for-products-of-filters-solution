# Strict inequalities for products of filters

**Status:** Preprint — not peer-reviewed.

**Author:** David Immanuel Eidenas

Late one night, I was looking for a small maths problem I could attempt to solve either entirely with AI or with substantial AI assistance. I selected this problem at random from Open Problem Garden and decided to give it a go. I make no statement or opinion on anything regarding this segment of mathematics beyond what I've published here. 

An affirmative solution to [Open Problem Garden problem 37339](https://www.openproblemgarden.org/op/strict_inequalities_for_products_of_filters), using Victor Porton's corrected definition of the oblique product.

For both the cofinite filter `Φ` on `ℕ` and the proposed one-sided neighbourhood filter `Δ₊` on `ℝ`, the proof establishes

```text
F ×_F^RLD F = ⊥ < F ⋉ F < F ×^RLD F.
```

Both input filters are proper and non-principal. The order is reverse inclusion of filter families; the second product is allowed to be the least, improper reloid.

## Verify the Lean proof

Install [Lean via elan](https://lean-lang.org/install/), then run from `lean/`:

```sh
lake exe cache get Mathlib.Data.Real.Basic Mathlib.Order.Filter.Cofinite Mathlib.Order.Interval.Finset.Nat
lake build
lake env lean Check.lean
```

The toolchain is **Lean 4.27.0**. Mathlib is pinned to
`a3a10db0e9d66acbebf76c5e6a135066525ac900` (release `v4.27.0`), and the manifest pins its transitive dependencies. The first command downloads precompiled dependencies; the project's own proofs are compiled from source by `lake build`.

The development and external checks have been built successfully. All proof dependencies use only Lean's standard axioms `propext`, `Classical.choice`, and `Quot.sound`; there are no admitted proofs or user-declared axioms.

### Paper–Lean correspondence

| Mathematical statement | Lean theorem |
|---|---|
| Source definition of meshing and positive-set duality | `mesh_iff_common_lower`, `mesh_iff_sets`, `mem_iff_meets_positive` |
| Principal image filter and funcoid graphs; reduction to positive sets and columns | `imageFilter_eq_generate`, `principalFuncoid_graph`, `productFuncoid_graph`, `upper_iff_positive_hits`, `upper_principal_iff_columns` |
| Outward reloid as a meet of principal relations | `outward_eq_iInf` |
| Oblique column filter, its properness, and the general chain | `oblique_eq_columnFilter`, `oblique_neBot`, `second_le_oblique`, `oblique_le_classical` |
| Classical product generated by rectangles | `classical_eq_prod`, `mem_classical_iff` |
| Complete cofinite-filter result | `frechet_solution` |
| `Δ` as the source's meet of symmetric real intervals | `delta_eq_iInf` |
| `Δ₊ = Δ ⊓ principal((0,+∞))` on **ℝ** | `deltaPlus_eq_inf` |
| Complete real-number result, including the exact proposed pair | `real_solution`, `proposed_pair_solution` |
| Both existential conjectures | `existential_solution` |

Filters and reloids use Mathlib's actual `Filter` type. The needed funcoids are pairs of filter-valued maps satisfying the source's meshing equivalence. The real example uses `Real`, not a rational approximation. Only the AGT definitions and operations needed for these results are developed; general composition and category theory are not claimed to be formalised.
